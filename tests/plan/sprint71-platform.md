## 1. Scope

The Sprint 71 surface under test is the new `cranelisp-platform` API: the `ABI_VERSION: u32` constant bump (1 → 2), the `CLAdt<T: CLAdtType = AnyAdt>` generic wrapper joining the CLInt/CLBool/CLFloat/CLString family with `read_tag` + `read_field<F>` + `own_field<F>` methods, the cranelisp-S-expression `Schema` parser and immutable `Schema` value, the `declare_platform!` macro's new `schema:` arm (auto-emitting marker types + a `LazyLock<Schema>` static), the two-field `HostCallbacks` growth (`alloc_with_tag`, `validate_schema` — nullable; stubbed null this sprint), the R1 wired-or-panic gate scoped to construction paths only, and the F2 source-move (deletion of `impl Default for HostContext`). The facade retirement (Phase C — folding `facades/platform.md` into source rustdoc + BC §5) does not change runtime behaviour and so does not appear in this plan as a behaviour-under-test; its compliance is verified by `/review` and the public-api baseline diff at Phase C close, not by a `#[test]`.

**Division of labour**: per `memory/feedback_unit_tests_with_dev.md`, unit tests inside `crates/cranelisp-platform/src/` are owned by `/dev platform` and authored alongside the Phase B implementation. `/qa` authors workspace-integration tests under `tests/` only — and the Sprint 71 surface is almost entirely in-crate (no DLL exists this sprint that exercises the new ADT-crossing-boundary API, because the test-platform cascade is deferred). `/qa`'s authored test set this sprint is therefore narrow.

End-to-end ADT-crossing-boundary tests (via `tests/spec_platforms.rs` + a new test platform DLL exercising marker types) are deferred to the host-side wiring sprint and tracked by SPRINT.md's `(N+6) /qa — round-trip integration tests once host-side wiring lands` future-FIXME.

**Anti-gap check**: I considered authoring a `tests/facade_retirement_compliance.rs` to verify `design/arch/facades/platform.md` is absent (file-not-exists) and that `design/arch/CLAUDE.md`'s exception list mentions `facades/platform.md`. **Conclusion**: this belongs to `/review` at Phase C close, not to `/qa`. Phase C's "Cross-reference sweep" + `/review platform` are the closure-gate. Adding a `#[test]` for file-absence-checks turns a one-time-irreversible operation into a perpetual assertion against an external structural state, which is a `feedback_no_premature_perf.md`-adjacent anti-pattern (testing the wrong layer of the project). Decision: no test authored.
