# 0038 — `SharedState` is the formal worker-shareable subset of `CompilerSession` state; per-symbol mutability discipline applies to all of it; `Introspection` lives here as a mode-conditional side store.

`SharedState` is the integration-layer struct that workers hold as `Arc<SharedState>` across thread boundaries — formally defined in `facades/int.md`. It carries: `symbol_tables: DashMap<ModuleFullPath, SymbolTable<Code, ()>>`, `scheduler: Arc<CompileScheduler>`, `cache: Arc<ObjectCache>`, `kept_dlls: DashMap<PathBuf, Arc<DllHandle>>`, `introspection: Option<DashMap<FQSymbol, Introspection>>`, `settings: SessionSettings`, `project_root`, `lib_dirs`, `platform_dirs`. Every field is interior-mutable (DashMap, Arc, atomics) so workers freely access via `&shared.field` with no exclusive borrow ever required; mutation flows through the contained types' own per-cell locks, with no merge-back step. `CompilerSession` separately holds the initiator-thread-only state (`watcher`, `current_repl_module`, `repl_input_active`, `worker_pool`, `warnings`) and one `Arc<SharedState>` clone for delegation.

**`Introspection` placement.** Per-symbol REPL/trace metadata — `source`, `sexp`, `clif_ir`, `disasm`, `code_size`, `compile_duration` — lives on `SharedState.introspection: Option<DashMap<FQSymbol, Introspection>>`. The outer `Option` is `Some(map)` iff REPL mode OR `CRANELISP_CODEGEN_TRACE` is set; production batch (`--run` non-trace, `--link`) leaves it `None` and pays zero per-symbol metadata overhead. Codegen workers populate `clif_ir`/`disasm`/`compile_duration`; the parser populates `source`/`sexp`. Both populate paths conditionally on `shared.introspection.is_some()`. Slash-command accessors (`Sess::symbol_clif(fq)`, `Sess::symbol_disasm(fq)`, etc. — all on `CompilerSession` for facade-surface convenience) read from `shared.introspection.as_ref()`.

**Per-symbol mutability via Phase 0 setup + `&SymbolTable` thereafter.** `register_module` runs Phase 0 synchronously: `parse → entry(m).or_default() → write_structural_decls + defn_order seed → drop RefMut`. After Phase 0, all SymbolTable access by workers is `&SymbolTable` + per-entry inner-DashMap locks. `process_form(shared, form, scope)` uses shared `shared.symbol_tables.get(scope)` (shard read lock), not `.entry(scope).or_default()` (shard write lock). `check_form` takes `&SymbolTable` (not `&mut`). Per-symbol writes go through `SymbolTable::insert_or_update(&self, sym, entry)` and `SymbolTable::write_code(&self, sym, code)` which acquire the inner DashMap's per-entry write lock briefly. The only `&mut SymbolTable` operations are: (a) Phase 0 (structural decls + initial `defn_order` seed); (b) per-form REPL appends to `defn_order` via `append_defn_order(&mut self, sym)`. Both are integration-layer operations on the initiator thread; workers never see `&mut SymbolTable`.

**Retracts Decision 9** (the `Introspection on SharedState` bullet was directionally correct but its field shape and the related `module_sources` placement were unspecified; this Decision pins both). `module_sources: DashMap<ModuleFullPath, Arc<str>>` is NOT a SharedState field — per-defn source lives on `Introspection.source` per Decision 39. The legacy `interfaces.md` `ModuleCodegenState` / `DefCodegen` shapes are explicitly retired.

**Mode discriminator is the Option, not a flag.** `shared.introspection.is_some()` is the canonical mode check. There is no separate `is_repl_mode: bool` or `enable_introspection: bool` field — the presence of the map IS the discriminator, which makes ill-formed states (introspection requested but map absent, or map present but never populated) unrepresentable.

Rejected alternatives: (a) place `Introspection` fields directly on `ModuleEntry::Def` — inflates the always-loaded SymbolTable in production batch with kilobytes of unused per-defn metadata; forces codegen to populate unconditionally (the trace-flag conditionality has no field-level expression); contradicts the trend of Decisions 25/26/33 where serde-skipped runtime state lives on `Def` only when always-needed (`code`, `platform_fn_ptr`); (b) `Introspection: HashMap<FQSymbol, Introspection>` always present (empty in production) — loses the zero-cost discriminator; production batch carries an empty DashMap with non-zero overhead; (c) per-module `Introspection: HashMap<Symbol, Introspection>` on `SymbolTable` — couples introspection to the cache-serialisable type (Decision 34) and forces serde-skip plumbing on every field; per-FQSymbol map at SharedState level keeps the storage flat and the cache shape clean.

Canonical locations: `facades/int.md` `SharedState` + `Introspection` + `WatcherChannel` + `WorkerPool` + `DllHandle` definitions; `crates/cranelisp-types/src/module.rs` (no change to `ModuleEntry::Def` shape — current fields stand); `src/session_v4.rs` (concrete struct). Owner: `/arch` for the facade text; `/int` for the implementation; `/typecheck` for the SymbolTable signature changes per FIXME 0008. Rationale: Principle 11 (single pipeline — one mode discriminator at the integration layer, not scattered field-level checks) + Principle 7 (single source of truth — `shared.introspection` is the one place per-symbol REPL metadata lives) + Principle 3 (`cranelisp-types` stays Cranelift-ignorant — `Introspection`'s `clif_ir`/`disasm` are Strings, not Cranelift types) + Principle 6 (complexity budget — production batch carries no per-symbol overhead).
