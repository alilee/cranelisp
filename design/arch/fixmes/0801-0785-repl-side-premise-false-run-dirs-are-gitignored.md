# FIXME 0785's `/repl`-side item is already closed — `repl/demos/runs/` is git-ignored, and the two demo sources were repaired at S114

## Issue

0785 lists eleven `repl/demos/runs/*` directories as **committed demo fixtures**
carrying the invalid return-position `:Type` form, and item 3 of its proposed
resolution assigns their repair to `/repl`. Verified at HEAD 2026-07-21, both
halves of that premise are false:

1. **`repl/demos/runs/` is git-ignored** — `.gitignore:17`. `git ls-files
   repl/demos/runs` returns nothing; `git check-ignore -v` confirms the rule.
   The directories are per-replay run artifacts (the player `chdir`s into a
   fresh timestamped dir so `.cache`/`user.cl`/`.cranelisp_history` are isolated
   per run — `repl/demos/CLAUDE.md` §"Run isolation"). They are regenerated by
   the next replay and are not fixtures of anything.

2. **The two tracked sources are already correct.**
   `repl/demos/05-traits.demo:45` and `repl/demos/archive/ring2a.demo:40` both
   read `(deftrait Sizeable (size [x] Int))` — the valid §7.1.1 form — repaired
   in commit `33e813e3` (S114 Phase 6b). A full `grep -rn "\] :"` across every
   `.demo` in `repl/demos/` and `repl/demos/archive/` returns **zero** hits. The
   22 files still carrying `(size [:a x] :Int)` are all under
   `repl/demos/runs/`, i.e. stale ignored output written by replays that predate
   `33e813e3`; the fresh full-sweep replay of 2026-07-21 wrote the valid form.

The `_traits-probe` directory named in the dispatch (`(deftrait (Zeroable a)
(zed [] :a))`) is likewise an ignored run/probe artifact, not a fixture; there
is nothing to confirm or repair.

## Why this matters (it is not a bookkeeping nit)

0785's sequencing argument is load-bearing: it declares corpus repair a
**prerequisite** for the S116 `:`-fold implementation, because that wave turns
the invalid form into a reader error. Carrying an eleven-item `/repl` line into
that prerequisite implies eleven blocked repairs that do not exist, and it
mis-sizes the prerequisite. Ignored regeneration artifacts cannot light up a
test wave — nothing reads them.

The finding also cuts the other way and is worth keeping: 0785's own evidence
was gathered by a `grep` that did not distinguish tracked from ignored paths.
The candidate standing instrument 0785 proposes (a corpus lint parsing every
`.cl` fixture against the spec grammar) should be scoped to **tracked** files
for exactly this reason, or it will report the same phantom every sprint.

## Proposed resolution

1. `/qa` strikes the `repl/demos/runs/*` clause from 0785's `refers_to` and the
   `/repl` assignment from its resolution item 3, and re-counts the real corpus
   (the ~25 `tests/*.rs` positive fixtures, which are genuinely tracked and
   genuinely a prerequisite).
2. Scope the proposed corpus-lint instrument to git-tracked paths.
3. No `/repl` action is owed. `/repl` will not delete the stale run directories
   — they are ignored, harmless, and self-superseding — unless `/sprint` wants
   the tree tidied, in which case say so and it is one `rm -rf` of
   `repl/demos/runs/`.
