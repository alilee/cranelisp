# 0034 — Cache schema is versioned by an explicit `schema_version: u32` field on the serialised `SymbolTable`; mismatch invalidates the cache as if dependencies changed

`.meta.json` carries a `schema_version: u32` field at the top of the serialised `SymbolTable` (or a thin `CacheEnvelope { schema_version, table: SymbolTable }` wrapper if `SymbolTable`'s own derive-`Deserialize` cannot be made forward-compatible). Cache-load reads the version first; if it does not match the current `CACHE_SCHEMA_VERSION` constant (defined in `crates/cranelisp-backend/src/cache/mod.rs`), the cache entry is treated as stale — the same code path that fires when source mtime or dependency hash changes. This guarantees: (a) a developer pulling main with a Phase 5 cache-shape change never sees a cryptic deserialisation error; (b) old caches do not silently skip typecheck on a stale shape that happens to deserialise into the new fields with wrong defaults. The version constant bumps every time a new `SymbolTable` field changes the serialised shape (additions of `#[serde(default)]` fields do NOT require a bump if the default matches a fresh-build value; explicit-default field additions, deletions, and type changes DO require a bump). Sprint 58 Step 5b ships `CACHE_SCHEMA_VERSION = 1` (the first numbered shape) — pre-Sprint-58 caches lack the field and are rejected as version-mismatch (`schema_version` defaults to `0` on deserialise via `#[serde(default)]`). Rejected alternatives: (a) hash the `serde_json::Value` shape of an empty `SymbolTable` to derive an implicit version — fragile (formatting changes invalidate; ordering-stable serialisation required); (b) gate cache invalidation on `cargo` build hash — too coarse (every recompile invalidates all caches even when shape unchanged); (c) keep the cache shape unversioned and accept "rare cryptic failures on shape changes" — violates Principle 5 (testability — failure modes must be explicit). Owner: `/backend` (defines `CACHE_SCHEMA_VERSION` constant in `cache/mod.rs`; implements the version check in cache-load); `/int` (worker cache-write path emits the field). Defined Sprint 58 Wave 1 alongside Step 5b. Canonical location: `crates/cranelisp-backend/src/cache/mod.rs` (constant + envelope shape). Rationale: Principle 5 (testability — explicit version makes shape-mismatch failures testable and recoverable) + Principle 8 (the cache envelope IS the serialised shape from Step 5b onward; not interim — every future shape change uses the same versioning protocol).
