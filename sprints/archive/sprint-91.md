### Thread A — Pillar 3 `/search` implementation (centerpiece)

Implement the importable-symbol search facility that was **fully designed but design-only in S90** (gated then on the 0432 root fix + the CF.1 floor, both of which landed in S90 W4). Design of record is coherent across four docs: `repl-embedded-agent.md §11.1–§11.9`, `repl/spec.md §17.19`, `design/int/agent.md §25`, `design/typecheck/signature-match.md`.

- **`/search <query>`** — REPL command over symbols **reachable but not yet imported**, on the lib search path ∪ project root, matched by **name and/or type signature, exact OR partial**. Row = name + signature + originating module + the exact `(import …)` form. A non-agent, default-build **session facility** (the agent reaches it via the ordinary tools-as-visible-REPL-commands pull).
- **Nice-worker background indexer** — the **read-or-produce-`.meta`** model (`/arch` R13–R18; see the Phase-2 addendum + `design/int/agent.md §25`): per reachable module, either read a valid `.meta` (no typecheck) or typecheck-into-staging + `write_meta` (no `.o`, never `register_module`). Indices are `pub(crate)` derived read-caches on `SharedState` (sibling to `introspection`, guard-excluded), rebuilt from `.meta` — not serialized, no schema bump. **Eager-from-REPL-startup** burn-down (REPL mode only — `--run`/`--link`/`--release` never arm it; index work yields to object codegen); a `/search` before completion serves partial results + an "indexing N modules…" note. **No session-state residue** (the four `SharedState` maps stay byte-unchanged; a benign `.meta` may be written).
- **CF.2 containment** (Pillar 3 does not ship without it) — a new nice-worker indexer `catch_unwind`: convert an unwind on an un-typecheckable reachable module to a logged per-module index-skip; continue the burn-down; never kill the thread. (CF.1 — the eval-thread validator catch — already shipped S90 W4.)
- **`signature_matches_exact` + `signature_matches_partial`** exported from `cranelisp-typecheck` (partial = structural-contains, no unifier). Two additive `public-api.txt` lines, dispositioned in this change-set per S67 baseline-diff discipline.

### Pillar-3 design-refinement ruling (S91 Phase-3 addendum)

**Reviewer:** `/arch`, 2026-06-25. **Trigger:** user design review during S91 Phase-3 surfaced two real problems with the S90 Pillar-3 in-memory/typecheck-and-discard/rebuild-every-trigger indexer: (1) a triggered first-`/search` re-typechecked the *entire* lib-path ∪ project-root even when valid `.meta.json` caches already existed; (2) an indexed module later `/import`ed re-typechecked from scratch (the index entry was a throwaway hint). The user agreed a better **read-or-produce-`.meta`, one-artifact** model. A **follow-up user correction** then replaced the trigger model entirely (R17), and a **second correction** pinned nice-worker flush handling (R18). **Durable record + full rulings:** `design/arch/repl-embedded-agent.md §11` (REFINEMENT BOX in §11.1; §11.1/§11.1a/§11.1a-flush/§11.1b/§11.2 refined; R13–R18 added). This addendum is the brief.

**The six rulings (verdict: APPROVE the refined model):**
