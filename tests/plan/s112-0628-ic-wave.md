## 8. Quality-risk assessment (USER-MANDATED)

Full register entry: `risks.md` §"S112 risk read". The verdict:

**Where this wave can break something the suite cannot see:**

1. **Wrong-accept inversion at the collapsed scan (highest).** Deleting
   `ClauseIndependence` leaves the post-drain ValueScan as the ONLY §3.11
   guard for multi-sig clauses. The failure mode is not wrong-reject (loud,
   caught by MS-1/MS-2/CP-1) but wrong-accept: a mis-computed per-clause
   `allowed_vars` classifies a genuinely-unpinned param as "admissibly
   polymorphic" — publishing a free-var scheme, the exact S110/S111
   `wrong-accept` class whose downstream face is a non-output-perturbing
   wrong-type read the suite is ~97% blind to. Cure in-plan: the boundary is
   pinned from BOTH sides at the closest shapes (MS-2/UW-5/UW-6 admissible
   vs MS-7 unpinned twin), and the memory-safety observables are retained
   through the unwind (UW-3/UW-4: type-error + `<invalid:` absence).
2. **Persisted-state reinterpretation without a bump (0644 hole)** — §7.4.
   Silent by construction: cache-hit bypasses typecheck, so no test that
   compiles fresh can see it. AG-1 + the §7.4 recommendation close it.
3. **Mangle/dispatch split-brain.** If entry-name and `SigDispatch` name ever
   derive from two mangle calls (pre- vs post-drain), the divergence surfaces
   as `undefined function` (loud) OR as dispatch to a stale `$Var` entry
   (silent wrong-code). AG-3 byte-identity + unit u2/u3 + AG-5 pin it.
4. **Trait-gate re-land regressing the green HKT corpus.** The S111 CS-4
   prototype was reverted precisely because the naive gate regressed 5 e2e;
   the re-land is NOT verbatim (A2 moved rejection to declaration time).
   The migration lists + TB must-holds + AG-5 are the fence; the named 5
   migrate deliberately (§9), not silently.
5. **Ownership-relevant behaviour: what changes, what rides uncovered.**
   This wave adds NO new ownership mechanism — admitted poly/constrained
   clauses monomorphise through the EXISTING `pass4_monomorphise`/
   `ConstrainedFn` machinery, and back-flow only pins types earlier.
   What changes is the REACHABLE PROGRAM SET: shapes that never reached
