### Methodology migration — ACTIVE FROM S63 (~4–6 sprints)

`sprints/METHOD_PROPOSED.md` reframes delivery: the five per-crate compiler skills (`/frontend`, `/typecheck`, `/backend`, `/int`, `/platform`) collapse into one generic `/dev` narrow-deployed across all 6 crate-shaped surfaces (`cranelisp-frontend`, `cranelisp-typecheck`, `cranelisp-backend`, `cranelisp-runtime`, `cranelisp-platform`, `src/`), paired with `/design` (intent) and `/review` (change-set quality). Net 15 → 12 skills; specialization moves from skill defs into per-crate `design/{crate}/{crate}.md` + per-directory `CLAUDE.md` (the three-way content split per METHOD_PROPOSED §14.1).

The 13 migration tasks (M1–M13) cluster across ~4–6 sprints:

| Cluster | Tasks | Dominant cost | Sprint slot |
|---|---|---|---|
| **Open the arc** | M1 (skill defs), M9a (boilerplate strip), M11 (archive reimplementation.md), M13 (runtime ownership) | Cheap; user-approval-gated | S63 |
| **Content extraction** | M9b (decisions → draft design docs), M9c (conventions → CLAUDE.md) | Per-skill, parallelizable | S63 (initial) → S64 |
| **Per-crate design overviews** | M2 (6 × `design/{crate}/{crate}.md`) | 3-4 days; chases M9b | S64–S65 |
| **Cross-crate hygiene** | M3 (types crate consolidation), M4 (`cargo-public-api` setup) | M3 ≥1 sprint on its own | S65 (M3) + opportunistic (M4) |
| **Privacy + facade** | M5 (`pub(crate)` downgrade), M6 (facade modules per crate) | Each ≥1 sprint, sequential (M6 ⇐ M5 ⇐ M3) | S66 (M5), S67 (M6) |
| **CLAUDE.md + memory** | M8 (CLAUDE.md rework, chases M9c), M10 (memory retirement, chases M8) | 0.5 day each | S67–S68 |
| **FIXME store** | M7 (inline → `sprints/fixmes/NNNN-*.md`) | 0.5–1 day; opportunistic slot | Any time before M12 |
| **Close the arc** | M12 (METHOD_PROPOSED → METHOD rename) | 0.1 day; last | Final sprint of arc |

Concurrency work (resuming S62 partial design docs) and FQTypeName migration both queue **behind** this arc — they re-enter the queue once the new triad is live and the per-crate design doc surface is established.
